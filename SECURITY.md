# Security

This code is a draft. No outside firm has audited it. Value held in a deployment of this code can be lost.
The reviews that the code had, their findings and the open items are in [`AUDIT.md`](AUDIT.md).

To report a vulnerability, write to **info@theselfrule.org**. Do not open a public issue or post the details in a forum.
Please include the affected file, the steps, and the impact. We will publish serious findings when it is safe to do so.

There is no bug bounty at this time.
